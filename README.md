# Day 1 - Log Analysis

This project contains a Jupyter Notebook that analyzes authentication logs.

The notebook:
- Counts failed login attempts.
- Extracts IP addresses using regular expressions.
- Displays the IP addresses with the most failed attempts.

## How to Run

1. Open `Day-1-Activities (1).ipynb` in VS Code.
2. Select the Python `.venv` kernel.
3. Run all notebook cells.
